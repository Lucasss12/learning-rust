# Skill : book-summary

## Objectif

Créer une fiche de révision en Markdown à partir d'un chapitre du livre "The Rust Programming Language" (version française) dans le dossier `doc`.

Cette fiche est destinée à accompagner la lecture du chapitre, pas à la remplacer.

## Consignes

- Se baser sur la version française officielle du Rust Book.
- Ne pas recopier le chapitre.
- Reformuler les explications avec ses propres mots.
- Être fidèle au contenu du chapitre.
- N'introduis jamais un concept qui n'a pas encore été vu dans le chapitre.
- Conserver les termes techniques Rust en anglais lorsqu'ils sont officiels (ownership, borrowing, lifetime, trait...).

## Structure

# Chapitre X — Nom du chapitre

## Objectif du chapitre

Décrire en quelques phrases ce que ce chapitre apporte.

## Concepts abordés

Lister tous les concepts introduits.

Pour chaque concept :

- Définition
- Pourquoi il existe
- Quand l'utiliser
- Erreurs fréquentes
- À retenir

## Nouveaux mots-clés

Lister les nouveaux mots-clés Rust rencontrés.

## Fonctions, méthodes et macros importantes

Lister celles introduites dans le chapitre avec une courte explication.

## Schéma mental

Expliquer comment les différents concepts sont liés entre eux.

## Comparaison avec JavaScript / TypeScript

Lorsque c'est pertinent, expliquer les différences de fonctionnement.

## Pièges classiques

Lister les erreurs que font les débutants.

## Résumé

5 à 10 points clés maximum.
